# Deadpan Forecasts for Cities That Do Not Exist

bounty page: https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c

One line, at most 160 characters: a weather forecast for a city that does
not exist, absurd but deadpan like a real forecaster, with a concrete
image, number and detail. The entry (127 characters):

> Tomorrow in New Blorp: 4 cm of sideways rain, winds filing for divorce, and a 90 percent chance your umbrella gives up by noon.

## Run it

```sh
npx tsx main.ts
```

`main.ts` reads the line from `entry.txt` and writes it verbatim to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (the output directory is tried first;
`$MAKEFUN_BOT_DIR` is only a fallback, since the grader's `/bot` is
read-only).
